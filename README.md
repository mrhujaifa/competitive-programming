# Competitive Programming

My competitive programming workspace. Currently practising in C.

## Structure
- `CODEFORCES/PRACTICE` — independent Codeforces problem practice by rating.
- `CODEFORCES/CONTESTS` — Codeforces contest work.
- `CODEFORCES/GROUPS` — problems from Codeforces groups and training tracks.
- `ALGORITHMS` — reusable algorithm implementations and learning notes.

## Problem folder rule
Every problem folder contains:
- `solution.c` — my C implementation.
- `notes.md` — problem idea, conditions, approach, complexity and lessons.
